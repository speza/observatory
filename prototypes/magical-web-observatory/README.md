# Magical web Observatory POC

Disposable native SVG/CSS Atlas validation answering one question:

> Can Mineral Ledger stay legible at production-shaped density, explain what
> changed, and carry the operator from attention into useful work?

Run it:

```sh
bun install
bun run start
```

Open <http://127.0.0.1:4173/prototype/observatory?theme=light>.

Mineral Ledger uses oxide, ochre, verdigris, slate and plum over a twelve-Goal,
seventy-five-Agent stress fixture. The same data is available as the spatial
**Atlas** and grouped **Ledger**. **Catch up since 08:30** exposes recent change
facts, and an Agent's **Open work surface** action demonstrates the future
terminal/diff/evidence composition without creating a PTY.

Use the header control or press `T` to switch between Day map and Night map.
Press `A` to toggle the Attention Queue.

Drag the world to pan, use the mouse wheel or the on-screen controls to zoom,
and double-click the world or press `0` to reset the viewport.

Selection, camera and lens state survive the simulated work-surface handoff.
This prototype is read-only, in-memory and deliberately isolated from the
production Universe, SQLite store and SessionHost adapters. Completed renderer,
interaction and broad art-direction decisions are preserved beside the active
Atlas refinement. PixiJS, rejected art directions and losing Atlas palette
implementations have been removed. Do not promote these components directly
into maintained source.
